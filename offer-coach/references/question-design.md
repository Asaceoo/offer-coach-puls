# 面试题设计规则（深度版 v3 · 八类）

## 总量与分配
每岗位 **55 题左右（八类之和须落在 51~60）**，八类分配（JD 信息薄时岗位职责/情景类取下限）：

| 类别 | 题数 | 题目来源 |
|---|---|---|
| 岗位职责深挖 | 8~9 | report.md 第三部分核心要求逐条映射，1~2 题深挖一条职责 |
| 行业认知 | 6~7 | 行业订单结构、工艺链、供应链、合规、竞品、区域产业带 |
| 通用软性 | 5~6 | 自我介绍、离职原因、职业规划、反问尽调、稳定性 |
| **专业术语解释** | 8~9 | 该岗位/行业必会概念（如 8D、MRP、IPQC、BOM、齐套率）：每题给术语 + 标准解释 + 答题要点 + 常见误用 |
| **情景问答题** | 8~9 | 模拟具体场景（客户当天要答复/插单/账实差异/供应商推诿）：给场景 → 期望处理顺序 → 加分点 → 雷区 |
| **案例梳理题** | 4~5 | 把用户自己的真实战例（story-cards/master.md）梳理成完整 STAR 结构——答案即用户的弹药，标注确认点 |
| **高频问题** | 8~9 | 该岗位/行业面试中出题频率最高的真题（从同业 JD、面经、招聘方视角归纳） |
| **压力测试题** | 4~6 | 面试官主动施压类，题型来源/子类型/接化发总原则见下方专节 |

**P0 必透题**总数 4~8 题，语法统一为题目前缀【P0】；构成=压力测试题全数计入 + 其余来源（跨行生死题/最强战场题/尽调反问题等）择优补足；55 题中 P0 做深、其余快速过。彩排可分批：首轮彩排全部 P0，后续轮次只深挖新增待强化题。

## 命题方法论（出题前先做四问，源自领域专家工作方式）

1. **反向工程 JD**：一句话 JD + 急聘信号 → 先推导"这家公司此刻为什么缺这个岗"（大概率是某类痛点刚爆发），每题锚定"我能解决他的痛点"。
2. **从最原始素材入手**，不用二手整理物：
   - 真实单据流（订单评审→BOM→MRP→采购→排程→日报→出货）
   - 真实系统界面与操作录屏（对应行业主流 ERP 等）
   - 同业 JD 原文 10+ 份对比、从业者一手讲述、工厂实拍视频
   - 行业上市公司招股书/年报（行业结构/利润/订单形态的权威叙述）
   - 目标公司档案（注册信息、关联企业、历史招聘岗位、老板背景）
3. **具体方法与工具**：关键事件法（STAR 严格版，只收事实）、价值流视角重写经历、Excel 手推一次 MRP/物料运算、TOC 瓶颈思维、视角互换评分法（自己写面试官评分表）、模拟面试录音复盘。
4. **第三方验证**：面试官追问深度、独立评委按评分表盲评、多公司面试结果对照、目标公司第三方信源核验、offer 条款与试用期标准一致性。题库头部写明这四条验证路径。

## 每题结构（八层，前七层缺一不可；素材功课可选）

1. **题干**
2. **考察点**：面试官在测什么（1 句）
3. **注意点**：追问陷阱与露馅信号——低分回答长什么样、哪些话说了必扣分
4. **参考答案**（结构示范）：**用用户 story-cards.md/master.md 的真实素材装填**（须至少引用 1 处条目或标（确认点：…）），可直接照讲的骨架 + 真实战例引用。**P0 题须双版本**：30~60 秒电梯版（结论+一个数字，3~5 句）+ 3 分钟展开版（完整结构）；其他题单版本即可；素材缺失或需用户核实处标注（确认点：…）；跨行者无经历可依处写【待补：与教练确认思路方向】。红线适配：参考答案是"对照标准"，不是可整段背诵的成品稿——凡属用户亲历的细节必须由其本人核实替换
5. **追问与应对**：预置面试官听到参考答案后的 1~2 个具体追问 + 应对要点——**P0 题至少 2 组，其他题至少 1 组**。面试是多回合游戏，只备第一回合等于没备。追问模式：术语题→"这个词在我们行业怎么用"；情景题→"加约束"（时间更紧/资源更少/老板不支持）；案例题→"数据怎么算的/如果重来"；软性题→"挑简历细节深挖/你为什么关心这个"；高频题→"展开讲细节/换你主导会怎么做"；压力题→"加码施压（更狠的后续/对同一点连环追/当场否定你的回答）"。**至少 1 组追问必须锚定该题的（确认点）或注意点中的露馅信号**。边界声明：追问层只覆盖前 2~3 回合，非常规问题靠思路层能力迁移 + 复盘新题回填闭环。
6. **彩排状态**（服务彩排闭环）：未彩排 / 经受住追问 / 待强化（附补强点）——首次生成时全部"未彩排"，每次压力彩排后逐题更新；题库头部「彩排记录」为汇总表（题号｜状态｜补强点｜彩排日期）。
7. **思路**：命题人逻辑——为什么这么答得分、这题在筛选什么人
8. （可选）**素材功课**：该题投递前需查证的原始素材清单（如工艺链资料、公司客户群、供应商分布）

**特殊格式题**（在七层基础上替换 4/5 层内容，追问与应对层仍必须保留）：
- **专业术语解释题**：标准解释（面试可直接说的一两句）+ 答题要点（怎么答显专业）+ 常见误用（说错什么露馅）+ 追问与应对，不用 STAR。
- **案例梳理题**：产出即用户可背的完整 STAR 弹药（事实/数字/结果全部来自真实素材），标（确认点）后由用户核实 + 追问与应对——这是唯一允许接近"成品"的题型，因为讲的是用户自己的事。

## 压力测试题专节（第八类）

**定义**：面试官主动施压、质疑、否定，考察真实反应与心理承压的题型。与情景问答的区别——情景问答考"事情怎么处理"，压力题考"你这个人怎么接招"。

**题型来源（按优先级，从报告既有信息生成，不凭空出题）**：
1. match-report 的关键缺口（行业经验不足/资历超标/薪资落差）→ 资历质疑类
2. positioning 的空窗状态/在职状态/履历时间线 → 空窗盘问类
3. JD 硬门槛与简历的差距项 → "你不符合"类
4. 调研发现的雇主特征（老板亲招/急招/单休）→ 现场逼谈类

**边界与去重规则**：①关键缺口类压力题只归压力测试题，通用软性/通用轨不得再出同缺口题；②空窗盘问归压力测试题，通用软性的稳定性题只出非空窗变体；③跨行"经验质疑"统一归压力测试题的资历质疑子类型。
4. 调研发现的雇主特征（老板亲招/急招/单休）→ 现场逼谈类

**固定子类型（4~6 题覆盖 3 种以上）**：
- **资历质疑**："五年经验应聘 1-3 年的岗，是不是找不到工作？"/"我觉得你 overqualified，留不住"
- **空窗盘问**："这一个月在干嘛？"→ 连环追到具体日程
- **失败 probing**："讲一次你最大的失败/被客户当众拒绝的经历"（考诚实度与复盘深度）
- **现场否定**："你这个回答我不满意，重来"/"你答的非我所问"（考不防御不崩溃）
- **逼谈**："就这个数，干不干？不干可以走了"（考底线与谈判姿态）
- **疲劳追问**：对同一点连续"再具体点/然后呢"直到卡住（考抗压与诚实边界）
- **兜底**：其他施压形态（群面围攻/HR+业务双簧/外企 direct challenge）归入最接近子类型，追问层自行加码；经复盘出现 2 次以上的新形态回填为新子类型

**参考答案总原则（接化发三层，所有压力题通用）**：
1. **接**——不防御不讨好，先承认事实本身（"是的，我空窗了一个月"）；防御性反驳和过度道歉都是扣分
2. **化**——把质疑重构为选择逻辑（"我应聘这个岗是因为…，这不是找不到工作，是主动收敛方向"），用一次主动选择替代被动解释
3. **发**——落到一个可验证证据收尾（履历/数字/作品），不纠缠情绪

**失效边界（接化发何时会显假）**：①只覆盖单轮施压——同一质疑被第二次提出时禁止重复同一结构，改用新证据；②"发"层无可验证证据时不用（见素材管线）；③面试官连续两轮否定同一点时，停止重构、直接问"您关注的核心是 X 吗"把话题拉回事实层。

**红线适配**：接化发是结构不是台词——三层措辞必须由用户用自己的真实事实改写，禁止原状背诵示例（红线 3）；"发"层无可验证证据时按失败 probing 素材管线降级处理。

**注意点必写**：该类题的露馅信号（声音变急/贬低前雇主/当场反问面试官/完美答案显虚假）。

**失败 probing 素材管线**（四级降级）：①**优先引用 story-cards 的失败卡（SC-Fxx）**；②无失败卡时从战例卡的「结果+代价边界」转化——带真实代价的战例即合格素材；③仍无则引导用户补 1 张失败卡，本题降级为思路示范 +【待补：与教练确认思路方向】；④彩排遇素材缺失型打穿，记入待强化并提示补素材，不虚构失败经历（红线1）。

## 出题方法
1. **岗位职责题**：从 report.md 第三部分的"核心要求"逐条映射。题目要具体到岗位场景。
   - 好例子："客诉说批次门扇开胶，客户要当天答复，你的处理顺序是什么？"
   - 坏例子："请描述你的品质管理经验。"
2. **行业轨**：结合该公司所在细分行业，考认知深度。跨行者必含"跨行必被问的 3 题"（行业认知/经验质疑/学习计划）。
3. **通用轨**：结合 report.md 第四部分的关键缺口设计压力题——面试官大概率会戳缺口。
4. **术语解释题**：从 profile 的核心要求与 JD 全文中提取必会概念，按"面试官可能问定义"的概率排序。
5. **情景题**：场景取自该岗位真实高频困境（从核心要求+隐含信号推导），一个场景一个决策点。
6. **高频题**：从同业 JD、公开面经归纳，标注"高频来源"。

## 难度与顺序
题库按八类分节；类内按"基础必答 → 专业深挖 → 压力情景"排序；头部给出 P0/P1 备考优先级。

## 禁止
- 给可整段背诵的成品稿（案例梳理题除外——讲的是用户自己的事；其余参考答案必须钉在用户真实素材上，虚构细节零容忍）
- 出与 JD 无关的题凑数
- 一题多问（一题只考一个点）
- 只给框架不给参考答案结构（v1 老格式）——用户需要的是"对照标准"，不是空骨架
