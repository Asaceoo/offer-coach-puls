# 面试题设计规则（深度版 v2 · 50 题）

## 总量与分配
每岗位 **50 题（45~55，七类之和）**，七类分配（JD 信息薄时岗位职责/情景类取下限）：

| 类别 | 题数 | 题目来源 |
|---|---|---|
| 岗位职责深挖 | 8~10 | profile.md 核心要求逐条映射，1~2 题深挖一条职责 |
| 行业认知 | 6~8 | 行业订单结构、工艺链、供应链、合规、竞品、区域产业带 |
| 通用软性 | 5~6 | 自我介绍、离职原因、职业规划、反问尽调、稳定性 |
| **专业术语解释** | 8~10 | 该岗位/行业必会概念（如 8D、MRP、IPQC、BOM、齐套率）：每题给术语 + 标准解释 + 答题要点 + 常见误用 |
| **情景问答题** | 8~10 | 模拟具体场景（客户当天要答复/插单/账实差异/供应商推诿）：给场景 → 期望处理顺序 → 加分点 → 雷区 |
| **案例梳理题** | 4~5 | 把用户自己的真实战例（story-cards/master.md）梳理成完整 STAR 结构——答案即用户的弹药，标注确认点 |
| **高频问题** | 8~10 | 该岗位/行业面试中出题频率最高的真题（从同业 JD、面经、招聘方视角归纳） |

**P0 必透题**照旧标注（3~5 题：跨行生死题、最强战场题、压力决胜题、尽调反问题）；30 题中 P0 做深、其余快速过。

## 命题方法论（出题前先做四问，源自领域专家工作方式）

1. **反向工程 JD**：一句话 JD + 急聘信号 → 先推导"这家公司此刻为什么缺这个岗"（大概率是某类痛点刚爆发），每题锚定"我能解决他的痛点"。
2. **从最原始素材入手**，不用二手整理物：
   - 真实单据流（订单评审→BOM→MRP→采购→排程→日报→出货）
   - 真实系统界面与操作录屏（对应行业主流 ERP 等）
   - 同业 JD 原文 10+ 份对比、从业者一手讲述、工厂实拍视频
   - 行业上市公司招股书/年报（行业结构/利润/订单形态的权威叙述）
   - 目标公司档案（注册信息、关联企业、历史招聘岗位、老板背景）
3. **具体方法与工具**：关键事件法（STAR 严格版，只收事实）、价值流视角重写经历、Excel 手推一次 MRP/物料运算、TOC 瓶颈思维、视角互换评分法（自己写面试官评分表）、模拟面试录音复盘。
4. **第三方验证**：面试官追问深度、独立评委按评分表盲评、多公司面试结果对照、目标公司第三方信源核验、offer 条款与试用期标准一致性。题库头部写明这四条验证路径。

## 每题六层结构（深度版，缺一不可）

1. **题干**
2. **考察点**：面试官在测什么（1 句）
3. **注意点**：追问陷阱与露馅信号——低分回答长什么样、面试官会往哪追问、哪些话说了必扣分
4. **参考答案**（结构示范）：**用用户 story-cards.md/master.md 的真实素材装填**，可直接照讲的骨架 + 真实战例引用；素材缺失或需用户核实处标注**（确认点：…）**；跨行者无经历可依处写【待补：与教练确认思路方向】。红线适配：参考答案是"对照标准"，不是可整段背诵的成品稿——凡属用户亲历的细节必须由其本人核实替换
5. **思路**：命题人逻辑——为什么这么答得分、这题在筛选什么人
6. （可选）**素材功课**：该题投递前需查证的原始素材清单（如工艺链资料、公司客户群、供应商分布）

**两类题的特殊格式**：
- **专业术语解释题**：给"标准解释（面试可直接说的一两句）+ 答题要点（怎么答显专业）+ 常见误用（说错什么露馅）"，不用 STAR。
- **案例梳理题**：产出即用户可背的完整 STAR 弹药（事实/数字/结果全部来自真实素材），标（确认点）后由用户核实——这是唯一允许接近"成品"的题型，因为讲的是用户自己的事。

## 出题方法
1. **岗位轨**：从 profile.md 的"核心要求"逐条映射。题目要具体到岗位场景。
   - 好例子："客诉说批次门扇开胶，客户要当天答复，你的处理顺序是什么？"
   - 坏例子："请描述你的品质管理经验。"
2. **行业轨**：结合该公司所在细分行业，考认知深度。跨行者必含"跨行必被问的 3 题"（行业认知/经验质疑/学习计划）。
3. **通用轨**：结合 match-report 的关键缺口设计压力题——面试官大概率会戳缺口。
4. **术语解释题**：从 profile 的核心要求与 JD 全文中提取必会概念，按"面试官可能问定义"的概率排序。
5. **情景题**：场景取自该岗位真实高频困境（从核心要求+隐含信号推导），一个场景一个决策点。
6. **高频题**：从同业 JD、公开面经归纳，标注"高频来源"。

## 难度与顺序
题库按七类分节；类内按"基础必答 → 专业深挖 → 压力情景"排序；头部给出 P0/P1 备考优先级。

## 禁止
- 给可整段背诵的成品稿（案例梳理题除外——讲的是用户自己的事；其余参考答案必须钉在用户真实素材上，虚构细节零容忍）
- 出与 JD 无关的题凑数
- 一题多问（一题只考一个点）
- 只给框架不给参考答案结构（v1 老格式）——用户需要的是"对照标准"，不是空骨架
