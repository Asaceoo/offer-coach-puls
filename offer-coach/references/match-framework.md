# 简历匹配诊断：三分法框架

诊断"用户 vs 岗位"差距时，把用户经历严格分成三类。每一条结论都必须引用简历原文（或 `resume/master.md` 中的对应条目），这是反虚构红线的落地机制：有引用才有结论。

## 三分法定义

| 类别 | 判定标准 | 输出要求 |
|---|---|---|
| 直接匹配 | 有同岗位/同职责的真实经历，且简历能提供证据 | 引用 `master.md` 条目 + 对应 JD 要求；**标注强度：主导 / 参与 / 协助**（按用户实际角色，不得把参与写成主导） |
| 可迁移能力 | 经历不在同一职责域，但底层能力可论证迁移 | 必须写出迁移逻辑链（A 场景锻炼了 B 能力 → 对应岗位的 C 要求），禁止只写"具备沟通能力" |
| 关键缺口 | 岗位要求而用户完全没有经历支撑 | 必须同时给"补法"：短期话术补法（面试怎么讲）或行动补法（投递前能做什么） |

**边界判定：职责相同、发生部门/角色不同**（如"销售侧处理客诉" vs "品质侧主导 8D 闭环"）：职责动作本身有真实经历 → 归直接匹配，但强度如实标"参与"并在总判断中点明场景差异；只有职责动作的核心环节（如品质侧的根因分析与纠正措施闭环）无经历时，该环节归关键缺口。

**禁止**：把"相关"写成"具备"；使用任何匹配百分比；用"基本符合""大致匹配"这类模糊结论——每条要么有证据归入前两类，要么老实归入缺口。

**反例对照（写诊断时逐条对照）**

| 反例（禁止这样写） | 正例（照这个标准写） |
|---|---|
| "候选人具备品质管理经验，基本符合要求。" | "简历'品质部轮岗期间参与免漆门产线巡检'（master.md·工作经历1）↔ JD 第 1 条 IPQC 检验，属直接匹配（参与级，非主导）。" |
| "沟通能力强，可胜任客诉处理。" | "简历'处理客户对门扇外观、包装破损的投诉 20+ 起'（master.md·工作经历1）→ 客诉一线应对可迁移；但 8D 报告无经历支撑，归入关键缺口，补法见下。" |
| "匹配度约 85%。" | 【禁止出现】改用三分法条目表达。 |

## 输出结构（节名以 report.md 第四部分为准）

1. **总判断**（3 句以内）：能不能投、核心竞争力是什么、最大风险是什么。
2. **直接匹配清单**：每条 = JD 要求 ↔ 简历原文证据（引用 `resume/master.md` 条目）。
3. **可迁移能力清单**：每条 = 迁移逻辑链。
4. **关键缺口清单**：每条 = 缺口 + 补法（话术/行动）。
5. **差距 Top 3**：从上面提炼，供会话精要版展示。

### 4.2 面试六维评估卡（与 4.1 三分法并列的第二层）

三分法回答"我配不配这个岗"，六维卡回答"**面试官会怎么给我打分、我在哪一维最容易翻车**"。六维固定不可增删：

| # | 维度 | 面试官在这一维真正测什么 |
|---|---|---|
| ① | 硬实力与岗位胜任力 | 专业知识、技能、经验、项目成果、行业认知——要「证据」：做过什么/怎么做的/结果如何 |
| ② | 软实力与思维方式 | 沟通表达、逻辑结构、解决问题、学习能力、团队协作、抗压、主动性、责任心——常比答案对错更被看重 |
| ③ | 岗位与团队匹配度 | 能力/经验/薪资期望/职业规划 与 JD、团队阶段、业务需求是否合拍（太强或太弱都不合适） |
| ④ | 动机与稳定性 | 为什么来这家、为什么离开上家、对岗位了解多少、能不能长期做——面试官最怕招来三个月就走 |
| ⑤ | 文化与价值观契合 | 工作风格、沟通方式、好不好合作、诚信、责任感 |
| ⑥ | 潜力与性价比 | 学习速度、可塑性、复盘能力、未来能承担什么、薪资是否在预算内 |

**输出形态（每维一个小节，A4 友好，不用宽表）**：
```
### ① 硬实力与岗位胜任力
- 他在测什么：…
- 你的证据：master.md·工作经历1 ——「…原文摘录…」（数字：…）
- 风险：…
- 可翻盘点：…
- 怎么证明：…
```

**填写规则**：
1. **红线一致性（硬要求）**：「你的证据」必须带 `master.md` 引用（`master.md·工作经历1` / `master.md·项目2` …）并给数字或原文摘录——六维卡位于第四部分，其条目属含结论条目，适用红线 1 判据（每维至少 1 处引用），无引用即不合规
2. **禁止复制三分法**：4.1 的证据行不得整行复制到 4.2；4.2 的「怎么证明」必须是**动作**（带什么作品、怎么开口、怎么演示），不是同一句话再说一遍
3. **缺源降级**：工作区无 `positioning.md` / `story-cards.md` 时，依赖这两源的维度（③定位、②⑤行为证据）写「【待补：需阶段 0 定位面谈/故事卡】」，并在第一部分提示先建库
4. **风险栏须写可翻盘点**：每维风险后附一句你手里的反向证据，避免整张卡只列风险（纯焦虑源）
5. **最弱维度判据**：① 该维证据全为空或全为【待补】；② 该维被面试必问却无证据；③ 调研/风险信号显示会被当场戳穿。并列时按 ①②③ 优先级取
6. **覆盖度自检**：任一维证据为空或全为【待补】→ 该维面试必挨打，必须在题库补题、在故事卡补素材，并在「最弱维度」点名



三分法定义表中的每条判定标准，落到输出时对号入座：有证据进 2，可论证进 3，无支撑进 4。两处用词保持一致：文档中"直接匹配 / 可迁移能力 / 关键缺口"三节名与模板节名一一对应，禁止改名或增删节。

## 定制简历的衔接规则

report.md 第四部分（匹配诊断）的结论直接驱动 tailored-resume.md：
- 直接匹配的经历 → 在定制简历中**前置、扩写、对齐 JD 关键词**。
- 可迁移经历 → 改写措辞，把迁移逻辑写进经历描述。
- 关键缺口 → 不在简历里造假，用"相邻经历最大化呈现 + 面试话术补"，并在建议区标注【待补：建议补充 XX 数据/经历】。
- 每条修改建议用"修改前 / 修改后"对照格式，"修改后"只重排和改写用户已有内容，新增内容一律标注【待补：…】（全局唯一待补语法，不使用其他写法）。**"修改后"不得提升动作强度（参与→协助→主导）、不得新增原文没有的数字**——此约束与诊断节的强度标注同源，同样约束定制简历。
