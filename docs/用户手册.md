# offer-coach 用户手册

> 版本：v1.0.5｜ 更新：2026-10-24

offer-coach 是一个求职全流程技能：上传岗位截图和简历，一次性拿到岗位分析、匹配诊断、定制简历和面试题；面试前后还有辅导计划、复盘和题库汇总。

## 1. 它能帮你做什么

| 阶段 | 你给什么 | 它给什么 |
|---|---|---|
| 看到岗位 | 岗位截图 / JD 文本 / 链接 | 岗位档案 + 四维分析（本质/核心要求/隐含要求/理想候选人） |
| 简历诊断 | 简历（首次上传后复用） | 直接匹配 / 可迁移能力 / 关键缺口 三分法报告 |
| 准备弹药 | 一句"出定制简历和面试题" | 定制简历（逐条修改前/后 + 重排版）+ 15~20 道分层面试题 |
| 收到面试通知 | 通知文本/截图 | 倒计时备战计划 + 可选自动提醒 |
| 面完一轮 | 口述面试情况 | 结构化复盘卡 + 卡点沉淀 |
| 周期收尾 | "汇总" | 全岗位题库合并文档 + 投递漏斗统计 |

## 2. 快速开始（一键全出）

1. 开新会话，直接发：岗位截图 + 你的简历文件，加一句"帮我分析下这个岗位"。
2. 它会一次性输出：岗位画像精要版（会话内看）+ 完整五件套（自动落盘）。
3. 信息不全时它只问一轮，答完即出结果。

五件套落盘位置：当前工作区 `offer-coach/jobs/{岗位ID}/` 下的 profile、match-report、tailored-resume、question-bank 四个文件 + 岗位池索引 `index.md`。

## 3. 日常使用

- **换岗位**：直接发新岗位截图，简历不用重传（只第一次需要）。
- **更新简历**：说"更新简历"并发新文件，之后所有分析基于新版。
- **收到面试**：把面试通知粘贴/截图发它 → 生成 D-3/D-1/D-0 计划，同意后自动建提醒。
- **面完复盘**：口述被问了什么、哪里卡壳 → 出复盘卡，卡点自动记入 playbook，下次辅导置顶提醒。
- **汇总**：说"把我面过的岗位题库汇总" → 去重合并导出（Markdown，要 Word 说一声）。

## 4. 题库规则

- 每岗位 15~20 题，岗位轨 6~8 / 行业轨 4~6 / 通用轨 4~5，轨内由易到难。
- 每题含：考察点、答题框架（STAR 等）、答题思路示例（示例仅供方向参考，须替换为你的真实经历）。
- 英文 JD：分析用中文，专业术语保留英文（如 8D、SPC、IATF 16949）。

## 5. 三条底线（它不会做的事）

1. 不虚构：简历建议全部引用你的原文，缺数据只标注【待补】不代编。
2. 不给匹配百分比：差距用三分法表达，不用伪精确数字。
3. 不自动投递：只帮你准备，投不投始终你决定。

## 6. 常见问题

**Q：截图糊了怎么办？**
它会一次性列出缺的字段让你补，不会挤牙膏式反复追问。

**Q：数据存在哪？会上传吗？**
全部存在本地工作区 `offer-coach/` 目录，不上传任何外部服务。

**Q：同一岗位发了两次 JD？**
按公司+岗位+地点+JD 相似度识别为同一岗位，增量更新并提示哪些结论需重算。
