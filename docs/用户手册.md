# offer-coach 用户手册

> 版本：v1.6.1｜ 更新：2026-10-25

## 1. 这个技能是干什么的

一个求职全流程教练：你发岗位截图/JD 和简历，它产出**可验证的投递决策报告**——这个岗位到底做什么、公司真正想招什么人、你匹配度如何、值不值得投、面试重点准备什么、有什么风险要提前确认。之后面试通知、复盘、汇总、谈薪、试用期，它全程陪跑。

所有数据只存在你自己电脑的工作区里，不上云。

## 2. 快速开始

1. 第一次用时它会先问 5 个定位问题（一次问齐）：目标岗位族排序、薪资底线与理想值、地理范围、行业偏好与排斥、当前状态与精力。答完落 `positioning.md`——**定位是岗位的第一道筛子，薪资低于底线或行业在排斥清单的岗位会被直接建议不投**。
2. 之后你只要发岗位截图（或粘贴 JD/链接）+ 简历，它会一次性产出：**一份全中文岗位报告 PDF**（自动落盘）+ 一份定制简历。
3. 信息不全时它只问一轮；答完即出结果。

产出位置：当前工作区 `offer-coach/exports/{岗位ID}-岗位报告.pdf`；定制简历在 `offer-coach/jobs/{岗位ID}/tailored-resume.md`。

## 3. 你能说的话（触发方式）

| 你说 | 它做 |
|---|---|
| "帮我看看这个岗位" + 截图/JD | 六部分岗位报告 + 定制简历 |
| "这个岗位怎么样" | 同上（不需要点名技能名） |
| "分析下我的简历和这个 JD" | 匹配诊断 |
| "帮我改简历" | 定制简历 |
| "收到面试通知了：……" | 面试辅导计划（D-3/D-1/D-0）+ 押题 + 可选提醒 |
| "面完了，问了……" | 结构化复盘卡 + 反哺话术库/题库 |
| "把题库汇总一下" | 跨岗位去重题库 + 投递漏斗 |
| "拿到 offer 了：……" | 谈薪准备（总包视角+比较矩阵） |
| "被拒了" | 拒因三层归因 |
| "入职了" | 30/60/90 天试用期计划 |

## 4. 报告里有什么（六部分）

| 部分 | 回答的问题 |
|---|---|
| 一、投递决策速览（七问） | 岗位是做什么的 / 日常工作内容 / 公司真正想招什么样的人 / 匹配度 / **值不值得投** / 面试重点 / 风险点与确认清单 |
| 二、岗位公司深度调研 | 工商概况 / 业务产品 / 行业地位与经营动态 / 组织与招聘信号 / 口碑与风险 / 对投递判断的影响 / 来源列表 |
| 三、岗位档案 | 四维分析：岗位本质 / 核心要求 / 隐含要求（JD 措辞→信号）/ 理想候选人 |
| 四、简历匹配诊断 | 直接匹配（引用你简历原文）/ 可迁移能力 / 关键缺口 / 差距 Top 3——**没有匹配百分比** |
| 五、题库 | 47~55 题，七类（见下） |
| 六、投递状态 | 状态与漏斗贡献 |

**铁律：一个 JD = 一份独立报告**，不同岗位绝不混在一份里。

## 5. 题库规则（七类 47~55 题）

| 类别 | 题数 | 长什么样 |
|---|---|---|
| 岗位职责深挖 | 8~10 | 考专业实操，一题一个决策点 |
| 行业认知 | 6~8 | 行业结构、格局、工艺、合规 |
| 通用软性 | 5~6 | 自我介绍/离职/规划/反问 |
| **专业术语解释** | 8~10 | 术语 + 面试可直接说的标准解释 + 答题要点 + 常见误用 |
| **情景问答** | 8~10 | 真实高频场景 + 期望处理顺序 + 加分点 + 雷区 |
| **案例梳理** | 4~5 | 把你的真实战例整理成完整 STAR 弹药 |
| **高频问题** | 8~10 | 该岗位面试出题频率最高的真题 |

每题含：考察点、注意点（追问陷阱）、参考答案（**用你的真实素材装填，标（确认点）**）、思路（命题人逻辑）。题库头部标 P0 必透题（3~5 题）。

## 6. 深度调研（公司背景）

分析岗位时它会按需搜索公司信息（工商、业务、招聘者身份、在招岗位全景、行业格局）。纪律：**BOSS 展示与工商矛盾时以调研为准并注明差异；查不到的写"（未核实）"，禁止推测填空**。调研结论写进报告第二部分，并可能修正岗位定性（真实案例：某"ERP 实施"标签公司实为精密五金制造，据此修正了 12 道题库题）。

## 7. 四条红线

1. **反虚构**：建议引用简历原文，缺数据标【待补】不代编
2. **无匹配百分比**：差距用三分法表达
3. **面试题给参考答案结构示范，不给背诵稿**：亲历细节由你核实替换
4. **不做自动投递**

## 8. 常见问题

- **报告是 PDF 吗？** 是，全中文，落 `exports/`；转换失败时降级交付 `report.md` 并说明原因。
- **英文 JD 呢？** 全中文分析，术语首现括注中文解释。
- **为什么先问定位？** 没有底线的分析是浪费——薪资低于底线的岗位直接建议不投。
- **数据会上云吗？** 不会，全部本地工作区文件。
