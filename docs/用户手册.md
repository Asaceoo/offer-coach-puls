# offer-coach 用户手册

> 版本：v1.11.0｜ 更新：2026-10-26

## 1. 这是什么

一个求职全流程教练。你发岗位截图/JD 和简历，它在**投递之前**给你一份可验证的决策材料：岗位到底做什么、公司真正想招什么人、我配不配、值不值得投、面试怎么准备、有哪些坑，以及——**面试官会按哪六维给我打分、我的证据够不够**。之后面试通知、复盘、汇总、谈薪、试用期全程陪跑。

所有数据只存在你本机的工作区里，不上云。

## 2. 快速开始

1. **第一次用**先答 5 个定位问题（一次问齐）：目标岗位族排序 / 薪资底线与理想值 / 地理范围 / 行业偏好与排斥 / 当前状态与能量。落 `positioning.md`——**定位是岗位的第一道筛子**，薪资低于底线或行业在排斥清单的岗位会被直接建议不投。同时建立故事卡库：战例卡（正向经历）+ **失败卡**（讲一次栽过的跟头，是压力题的合规素材源）。
2. **之后你只要发岗位截图（或粘贴 JD/链接）+ 简历**，它会一次性产出：
   - **岗位报告 PDF**（六部分，20 页左右）
   - **P0 精练卡 PDF**（一页 A4，面试前 24 小时只看这页）
   - **定制简历**（逐条修改前/后 + 单页 A4 重排版）
3. 信息不全时它只问一轮，答完即出结果。

产出位置：`offer-coach/exports/`（报告与精练卡 PDF）、`offer-coach/jobs/{岗位ID}/`（定制简历、辅导计划、复盘卡、offer 记录）。

## 3. 你说的话与它做的事

| 你说 | 它做 |
|---|---|
| "帮我看看这个岗位" + 截图 | 六部分报告 + 精练卡 + 定制简历 |
| "这个岗位怎么样" | 同上（不需要点名技能名） |
| "我简历能投这个吗" | 匹配诊断（3.1 三分法 + 4.2 六维评估卡） |
| "帮我改简历" | 定制简历 |
| "收到面试通知了：……" | 辅导计划（D-3/D-1/D-0 + 押题 + 能量建议 + 可选提醒） |
| "面完了，问了……" | 复盘卡（押题命中率/卡点/下一场第一个要改的动作）→ 反哺话术库与题库 |
| "把题库汇总一下" | 跨岗位去重题库 + 投递漏斗 |
| "拿到 offer 了：……" | 谈薪准备（总包量化 + 定位对照 + 话术要点） |
| "被拒了" | 拒因三层归因（HR 理由 / 自察 / 市场对照） |
| "入职了" | 30-60-90 天试用期计划 |

## 4. 报告里有什么（六部分）

| 部分 | 回答什么 |
|---|---|
| 一 · 投递决策速览（七问） | 岗位做什么 / 日常内容 / 公司想招谁 / 匹配度 / **值不值得投** / 面试重点 / 风险与确认清单 |
| 二 · 岗位公司深度调研（八项） | 工商概况 / 业务产品 / 行业地位（含量化数字）/ 招聘信号 / 口碑风险 / **情报缺口清单** / 对投递判断的影响 / 来源 |
| 三 · 岗位档案 | 四维分析：岗位本质 / 核心要求（强度）/ 隐含要求（JD 措辞→信号）/ 理想候选人 / 与定位贴合度 |
| 四 · 简历匹配诊断 | **4.1 三分法**（直接匹配/可迁移/关键缺口，每条引用你简历原文，无匹配百分比）<br>**4.2 面试六维评估卡**（见下） |
| 五 · 题库 | 51~60 题，八类（见第 5 节） |
| 六 · 投递状态 | 状态快照、产出物计数、投递漏斗 |

### 4.2 面试六维评估卡怎么用

| 维度 | 他在测什么 | 你的证据 | 风险 | 怎么证明 |
|---|---|---|---|---|
| ① 硬实力与岗位胜任力 | 专业知识/技能/经验/项目成果/行业认知 | 引用简历原文与数字 | 最可能被质疑的点 | 带什么作品、怎么讲 |
| ② 软实力与思维方式 | 沟通/逻辑/解决问题/学习/协作/抗压/主动性 | 行为证据（故事卡） | 滑向形容词 | 落到动作粒度 |
| ③ 岗位与团队匹配度 | 能力/薪资/规划与 JD、团队阶段合不合 | 定位 + JD 硬门槛 + 调研的团队阶段 | 降级感或过配 | 反问分工与验收 |
| ④ 动机与稳定性 | 为何来/为何走/懂多少/能待多久 | 时间线 + 离职叙事 + 调研深度 | 诚信雷区 | 先统一口径 |
| ⑤ 文化与价值观契合 | 工作风格/沟通/好不好合作/诚信 | 代价边界 + 冲突处理战例 | 留痕被读作僵 | 给"给台阶但记录不改" |
| ⑥ 潜力与性价比 | 学得快不快/能长成什么/薪资在预算内 | 自学经历 + 复盘改进 + 薪资区间 | 被按新人价谈 | 起点让、职责要 |

用法：**面试当天先看 P0 精练卡（1 页），再看六维卡的"风险"栏**。卡片末尾会点名你当前**最弱维度**——那一维就是要重点补的方向。

## 5. 题库规则（八类 51~60 题）

| 类别 | 题数 | 长什么样 |
|---|---|---|
| 岗位职责深挖 | 8~9 | 考专业实操，一题一个决策点 |
| 行业认知 | 6~7 | 行业结构、格局、工艺、合规 |
| 通用软性 | 5~6 | 自我介绍/离职/规划/反问 |
| 专业术语解释 | 8~9 | 术语 + 面试可直接说的标准解释 + 答题要点 + 常见误用 |
| 情景问答 | 8~9 | 真实高频场景 + 期望处理顺序 + 加分点 + 雷区 |
| 案例梳理 | 4~5 | 把你的真实战例整理成完整 STAR 弹药 |
| 高频问题 | 8~9 | 该岗位面试出题频率最高的真题 |
| 压力测试题 | 4~6 | 资历质疑/空窗盘问/失败 probing/现场否定/现场逼谈/疲劳追问（+ 双簧变体） |

每题八层：考察点 / 注意点 / 参考答案（真实素材装填，标确认点；**P0 题双版本：30~60 秒版 + 3 分钟版**）/ 追问与应对 / 彩排状态 / 思路 /（可选）素材功课。

**压力题的应答总原则「接化发」**：接（承认事实，不防御不讨好）→ 化（把质疑重构为主动选择）→ 发（落到可验证证据）。它是结构不是台词——禁止原状背诵；"发"层没有证据时按失败卡降级处理，绝不虚构失败经历。

**压力彩排**：报告交付前，AI 演面试官对 P0 题深挖 2~3 轮（至少 1 个预置外新追问），打穿判据三条（依赖未核实数字 / 视情况而定式回答 / 撞上露馅信号），打穿点回写题目并记入彩排记录。**押题优先级：待强化 > 未彩排 > 经受住追问**，且最弱维度必押一题。

## 6. 调研纪律（为什么结论可信）

- **信源分级**：一手（官网/公众号/电商页/地图）> 二手（工商黄页/招聘平台/新闻）> 三手（AI 摘要）；员工社区只作口碑线索，不计入事实交叉验证
- **交叉验证**：写入"事实"须 ≥2 个独立来源（转载链算 1 个），否则标注"（单一来源，待交叉验证）"
- **一手直取**：官网/公众号用直取正文，不采信搜索摘要；抓不到记"官网不可达"并进情报缺口
- **信息保鲜**：每条信息带来源+日期；报告超 7 天用于新决策前需重新核验
- **行业量化**：行业节至少给 1 个可引用数字，取不到标"（未获取）"
- **关键人调研**：招聘者/法人/预判面试官的公开痕迹
- **情报缺口清单**：查不到但重要的信息单独列节，每条带"为什么重要 + 面试怎么问"——**缺口自动变成确认问题**
- **零信源兜底**：完全查无此司时，公司字段全标（未核实），"值不值得投"仅按岗位匹配+薪资+地理三项判断，严禁挪用同名企业信息

## 7. 四条红线

1. **反虚构**：结论引用简历原文，缺数据标【待补】不代编
2. **无匹配百分比**：差距用三分法 + 六维卡表达
3. **不给背诵稿**：参考答案与精练卡都是骨架，亲历细节由你核实替换
4. **不做自动投递**

## 8. 常见问题

- **报告是 PDF 吗？** 是，全中文；转换失败时降级交付 `report.md` 并说明原因
- **英文 JD 呢？** 全中文分析，术语首现括注中文解释
- **为什么先问定位？** 没有底线的分析是浪费——薪资低于底线的岗位直接建议不投
- **精练卡和报告怎么分工？** 报告是全量底稿（考前存档），精练卡是考前 24 小时的速查页
- **分享报告给别人要注意什么？** 导出物含姓名/联系方式/薪酬底线，转发前删掉
- **数据会上云吗？** 不会，全部本地工作区文件
